# Bundled FIGlet fonts

This extension bundles 246 FIGlet (`.flf`) fonts, originally sourced from the FIGlet font collection at <http://www.jave.de/figlet/fonts.html>.

**Licensing:** FIGlet fonts are authored by many individuals and carry varied terms. Most of these files contain no explicit license; some carry an author copyright notice. Each font's original header comment (including author credit) is preserved verbatim in the `.flf` file. These fonts are redistributed on that basis and are **not** relicensed under the extension's Apache-2.0 license. If you intend to redistribute, review individual font headers.
